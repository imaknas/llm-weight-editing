   同一個專案裡的 `agent-memory` 分支是私人的工作筆記,不能推出去(不要用 `--all` 或 `--mirror`)。
3. ✅ **`docs/registry-models-draft.yaml` 已從檔案與歷史中移除。**
4. **不公開的東西(已經被排除在版本控制外,公開前我會再確認一次):** Gemma 的權重、所有修改檔、`.env`、`data/` 整個資料夾。
5. ★ **要不要公開六個回合的逐字紀錄與寫入紀錄。** 文章的「怎麼自己驗證」需要它們。內容是模型的回應、工具呼叫與工具輸出(含 Gemma 權重的小片段數值與模型產生的文字),
   沒有個人資料;我會先掃過本機路徑。Gemma 權重片段是否受 Gemma 條款限制,我傾向保守:只公開寫入的請求(運算式)與模型的文字回應,不公開讀出來的權重數值。
